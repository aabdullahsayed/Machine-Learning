# Practice — Formulas & Functions

1. Build a grading formula using nested `IF` for scores `[95, 82, 71, 55]`, then rebuild the same logic using `IFS()` — compare readability.
2. Create two small tables (a "Sales" table with Product IDs, and a "Product Catalog" table with ID/Name/Price). Use VLOOKUP, then INDEX-MATCH, then XLOOKUP to pull the price into the Sales table — confirm all three give the same result.
3. Using a sales dataset with Region and Revenue columns, write `SUMIF`, `COUNTIF`, and `AVERAGEIF` formulas filtered to one region, then `SUMIFS`/`COUNTIFS` with 2 conditions.
4. Compute someone's age from a birthdate using `DATEDIF`, and compute "days since last order" using `TODAY() - OrderDate`.
5. If you have Excel 365: use `FILTER()` to pull all rows where Revenue > 1000 AND Region = "West", and `UNIQUE()` + `SORT()` to build a ranked list of top customers.
6. Build a realistic 3-layer nested formula (lookup + conditional + rounding) using the "build in layers" strategy from `Nested-Formulas.md` — verify each layer in a helper cell before combining.
