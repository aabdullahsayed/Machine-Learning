# Excel Keyboard Shortcuts — Reference

## Navigation
| Shortcut | Action |
|---|---|
| `Ctrl + Arrow key` | Jump to the edge of a data region |
| `Ctrl + Home` | Go to cell A1 |
| `Ctrl + End` | Go to the last used cell |
| `Ctrl + Page Up/Down` | Switch between worksheet tabs |
| `F5` or `Ctrl+G` | Go To a specific cell/range |
| `Ctrl + F` | Find |
| `Ctrl + H` | Find & Replace |

## Selection
| Shortcut | Action |
|---|---|
| `Ctrl + Shift + Arrow` | Extend selection to edge of data region |
| `Ctrl + Space` | Select entire column |
| `Shift + Space` | Select entire row |
| `Ctrl + A` | Select all (entire data region, or whole sheet if pressed twice) |
| `Ctrl + Click` | Select multiple non-adjacent cells/ranges |

## Editing
| Shortcut | Action |
|---|---|
| `F2` | Edit the active cell |
| `F4` | Toggle absolute/relative reference while editing a formula |
| `Ctrl + D` | Fill down (copy the cell above) |
| `Ctrl + R` | Fill right |
| `Ctrl + ;` | Insert today's date |
| `Alt + =` | AutoSum |
| `Ctrl + Z` / `Ctrl + Y` | Undo / Redo |

## Formatting
| Shortcut | Action |
|---|---|
| `Ctrl + 1` | Format Cells dialog |
| `Ctrl + B / I / U` | Bold / Italic / Underline |
| `Ctrl + Shift + $` | Apply currency format |
| `Ctrl + Shift + %` | Apply percentage format |
| `Ctrl + T` | Convert range to a Table |

## Data & Analysis
| Shortcut | Action |
|---|---|
| `Ctrl + Shift + L` | Toggle AutoFilter |
| `Alt + F5` | Refresh PivotTable |
| `Alt + D + P` | Open PivotTable Wizard (legacy, still works) |
| `Alt + F11` | Open VBA Editor |
| `Alt + F8` | Open Macro dialog |

## Formula auditing
| Shortcut | Action |
|---|---|
| `Ctrl + backtick (`)` | Toggle "show formulas" view |
| `Ctrl + [` | Trace precedents (jump to cells this formula depends on) |
| `F9` | Recalculate (or, with a formula portion selected, evaluate just that part) |
