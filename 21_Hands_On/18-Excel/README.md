# Excel Roadmap for Data Analyst 📊

A complete, practical, step-by-step Excel learning path for becoming job-ready as a Data Analyst — from absolute basics to Power Query/Power Pivot and portfolio-ready dashboard projects.

## How to use this repo
- Go folder by folder, **01 → 11**, in order — each builds on the last.
- Every folder has a `Practice.md` — actually do these on a real spreadsheet, don't just read.
- `10-Real-World-Projects/` gives you portfolio pieces to show employers.
- `11-Interview-Prep/` is your final revision before Data Analyst interviews.

## Folder Map

| Folder | Topic | Why it matters |
|---|---|---|
| 01 | Excel Basics | Foundation — navigation, formulas, references |
| 02 | Data Cleaning | 80% of real analyst work is cleaning messy data |
| 03 | Formulas & Functions | VLOOKUP/XLOOKUP, IF, statistical functions — daily tools |
| 04 | Data Analysis Tools | PivotTables, filtering, what-if analysis |
| 05 | Data Visualization | Charts, conditional formatting, sparklines |
| 06 | Power Tools | Power Query, Power Pivot, DAX — the modern analyst stack |
| 07 | Advanced Excel | Macros/VBA basics, dynamic arrays, LAMBDA |
| 08 | Statistics in Excel | Descriptive stats, correlation, regression |
| 09 | Reporting & Dashboards | Building professional, interactive dashboards |
| 10 | Real-World Projects | Portfolio projects (Sales, HR, Finance analytics) |
| 11 | Interview Prep | Common questions, live-task simulations, cheat sheet |

## Skill level checkpoints
- **After Folder 04**: You can do 90% of "junior Data Analyst" day-to-day tasks.
- **After Folder 06**: You're using the same tools as professional BI-adjacent analysts.
- **After Folder 10**: You have 3 portfolio projects to show in interviews/resumes.

## Prerequisites
None — this starts from zero. Any version of Excel (365 preferred for Power Query/dynamic arrays/XLOOKUP); Google Sheets equivalents are noted where they differ.
