# Practice — Excel Basics

1. Open a blank workbook. Practice `Ctrl+Home`, `Ctrl+End`, and `Ctrl+Arrow` navigation on a dataset you paste in (try any small CSV, or type 20 rows of sample sales data).
2. Freeze the top row of your dataset and scroll down — confirm headers stay visible.
3. Type a column of 10 numbers. Use `Alt+=` to AutoSum them. Then manually write `=AVERAGE()`, `=MAX()`, `=MIN()` for the same range.
4. Create a formula using a relative reference, copy it down 5 rows, and observe how the reference changes. Then redo it with an absolute reference (`$`) and observe it stays fixed.
5. Format a column of raw decimal numbers (e.g., `0.05, 0.12, 0.20`) as percentages, and a column of raw numbers as currency.
6. Deliberately import or type a number as text (e.g., type `'42` with a leading apostrophe) and try to `SUM()` it along with real numbers — confirm it's excluded, then fix it with Text to Columns or `VALUE()`.
