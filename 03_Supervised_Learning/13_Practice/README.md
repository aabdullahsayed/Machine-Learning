# 📘 ML Maths Made Easy

A beginner-friendly guide to the math behind Machine Learning — explained in plain English, with a hands-on notebook.

## 📂 What's inside

| File | What you'll learn |
|---|---|
| `01_linear_algebra_basics.md` | Vectors, matrices, dot products — the "data language" of ML |
| `02_calculus_basics.md` | Derivatives & slopes — how ML models learn to improve |
| `03_gradient_descent.md` | The core algorithm that trains almost every ML model |
| `04_supervised_learning.md` | What supervised learning is, with simple real-life examples |
| `notebooks/gradient_descent_demo.ipynb` | Code you can run to *see* gradient descent working |

## 🧭 Suggested order

1. Read `01` and `02` first — they're the toolkit.
2. Read `03` — this is the star of the show.
3. Read `04` — see how it all fits into real ML.
4. Open the notebook and run the cells — watch the math become a working model.

## 🎯 Who this is for

Anyone who knows basic algebra and wants to understand **what's actually happening inside** an ML model — no PhD required. Every concept is explained with a simple analogy before any formula shows up.

Happy learning! 🚀
