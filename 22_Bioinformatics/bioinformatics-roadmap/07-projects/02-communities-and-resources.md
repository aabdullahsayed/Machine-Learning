# Communities & Additional Resources

## Online Communities

- **Biostars** (biostars.org) — Q&A site, the "Stack Overflow of
  bioinformatics," excellent for troubleshooting specific tool errors
- **r/bioinformatics** — active subreddit, good for career/roadmap
  discussions too
- **Bioconductor support forum** — for R/Bioconductor-specific issues
- **SEQanswers** — sequencing-technology-focused forum

## Free Courses

- **Rosalind.info** — problem-based learning (mentioned above, worth
  repeating — it's the best free resource for a CS-background learner)
- **Coursera: Genomic Data Science Specialization** (Johns Hopkins) —
  practical, tool-oriented
- **EdX/HarvardX: Data Analysis for Life Sciences** — statistics-focused,
  pairs well with Phase 4
- **Software Carpentry / Data Carpentry** — free workshops/lessons on
  Unix, Git, Python, R for scientific computing
- **rnaseq.uoregon.edu** and similar university-hosted RNA-seq workshops
  — many universities post full workshop materials publicly

## Databases Worth Knowing How to Query

- **NCBI** (GenBank, SRA, PubMed, dbSNP)
- **Ensembl** — genome annotation, comparative genomics
- **UCSC Genome Browser** — visualization + annotation, widely used
- **UniProt** — protein sequence/function database
- **PDB** (Protein Data Bank) — structural data
- **GEO** (Gene Expression Omnibus) — public expression datasets, prime
  source for reproduction projects
- **Human Cell Atlas** — single-cell reference data
- **STRING** — protein-protein interaction networks
- **KEGG / Reactome** — pathway databases

## Getting Into a Lab (if in academia)

- Cold-email professors whose recent papers you've actually read (refer
  to specifics — shows genuine interest, not a mass email)
- Look for "lab rotation" or research assistant opportunities explicitly
  aimed at CS students — many genomics/computational biology labs
  actively want people with a strong programming background
- Contributing to a lab's open-source tool before joining is a strong
  differentiator (see project #12)

## A Note on Pace

This roadmap is comprehensive by design — you are not expected to
master everything before doing research. Many successful bioinformatics
researchers learn Phase 4–5 material *while* working on their first
project, looking things up as needed. Use this roadmap as a map, not a
strict prerequisite chain: once you've completed Phases 1–3, it's
reasonable to join a lab or start a project and fill in Phase 4–5 gaps
as they become relevant to your actual work.
