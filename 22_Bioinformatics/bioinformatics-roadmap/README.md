# Bioinformatics Research Roadmap for CS Students

A structured, phase-based path for a computer science student moving into
bioinformatics research — covering biology foundations, tools, algorithms,
statistics/ML, specialized subfields, key papers/books, and project ideas.

**Estimated total time:** 9–14 months of consistent part-time study (10–15 hrs/week),
faster if full-time.

## How to use this repo

Go in order the first time through. After Phase 1–2, you can branch into
whichever specialized topic (05) matches your research interest, and start a
project (07) in parallel — bioinformatics is learned best by doing.

## Folder Structure

| Folder | Contents |
|---|---|
| `01-foundations/` | Molecular biology & genetics primer for CS people |
| `02-programming/` | Python/R stack, Biopython, Unix, reproducibility |
| `03-algorithms/` | Core bioinformatics algorithms (alignment, assembly, phylogenetics) |
| `04-statistics-ml/` | Stats foundations + ML/deep learning in biology |
| `05-specialized-topics/` | Genomics, proteomics, structural bio, single-cell, etc. |
| `06-papers-books/` | Curated reading list — foundational papers & textbooks |
| `07-projects/` | Hands-on project ideas by skill level |

## Suggested Timeline

```
Month 1-2   Phase 1: Biology Foundations + Unix/Python for Bio
Month 2-3   Phase 2: Core Algorithms (alignment, DP, assembly)
Month 3-5   Phase 3: Statistics + ML for Biological Data
Month 5-7   Phase 4: Choose a specialization track, go deep
Month 6-9   Phase 5: Reproduce a paper, then run your own small project
Month 9+    Phase 6: Read broadly in your niche, start contributing
            (open-source tools, preprints, lab rotations, conferences)
```

## Core Philosophy

1. **Biology is the domain, CS is the toolkit.** Don't skip the biology —
   algorithms without biological grounding lead to research that doesn't
   ask meaningful questions.
2. **Reproduce before you innovate.** Re-running a published analysis from
   its paper teaches you more than reading ten papers passively.
3. **Learn tools in the context of a real dataset**, not in isolation —
   pick a small dataset in month 1 and keep returning to it.
4. **Read papers actively.** For every paper: what's the question, what's
   the method, what's the evidence, what would you critique?

Start with `01-foundations/01-biology-primer.md`.
