# Mathematics for ML 📐🤖

A practical, no-fluff guide to the math that actually shows up in Machine Learning and Deep Learning — every topic goes **pure math first, then "here's exactly where this shows up in ML/DL."**

## How each file is structured
1. **Math explanation** — definitions, notation, worked examples, by hand.
2. **In ML/DL** — where this exact concept is used in real models/training (with code).

## Folder Map

| Folder | Topic |
|---|---|
| 01 | Linear Algebra (vectors, matrices, eigenvalues, SVD) |
| 02 | Calculus (derivatives, **gradient**, Jacobian/Hessian, chain rule) |
| 03 | Probability (distributions, Bayes' theorem, expectation) |
| 04 | Statistics (MLE, hypothesis testing, bias-variance) |
| 05 | Optimization (gradient descent, SGD variants, convexity, Lagrange multipliers) |
| 06 | Information Theory (entropy, cross-entropy, KL divergence) |
| 07 | ML Applications (backprop, loss functions, regularization, PCA — tying it all together) |
| 08 | Interview Prep |

## Suggested order
Go **01 → 08** in order. Calculus (`02`) is the heart of this repo — the `Gradient.md` file there is the single most important concept for understanding how neural networks learn.

## Prerequisites
High-school algebra. No prior calculus/linear algebra required — each topic builds from first principles before connecting to ML.
